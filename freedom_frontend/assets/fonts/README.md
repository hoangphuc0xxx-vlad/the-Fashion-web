# Freedom storefront fonts

Local WOFF2 files for Cormorant Garamond (normal and italic) and Manrope (normal), variable weights 400–700. Latin, Latin Extended and Vietnamese subsets are included. The browser selects the matching subset using the unicode ranges in `../../storefront-fonts.css`.

Downloaded on 2026-10-18 from the official Google Fonts CSS API. Exact font download URLs are recorded in `sources.json`. The site loads the files locally and does not call Google Fonts at runtime.

- Cormorant Garamond upstream: https://github.com/google/fonts/tree/main/ofl/cormorantgaramond
- Manrope upstream: https://github.com/google/fonts/tree/main/ofl/manrope
- Font licenses are bundled in `cormorant-garamond-OFL.txt` and `manrope-OFL.txt`.

`../../storefront-type.css` applies the font pair to the customer storefront and customer dialogs. Administration screens keep their existing typography.
